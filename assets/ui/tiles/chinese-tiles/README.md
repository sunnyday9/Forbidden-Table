English rank/suit abbreviations have been removed from the visible tile faces in V2.1. Names remain available through inspection and accessible labels. White dragon uses the supplied framed face, rather than printing 白 or a Latin W.

[manifest.json](manifest.json) records exact asset hashes, source URLs, dimensions, and the existing Domain TileDefinition IDs. Nominal size is 272×360; one source face is 271×360, preserved without alteration. The gallery and native Figma use contain scaling. No offline recoloring, cropping, or painting was applied.

Legacy fixture HON:W means White dragon; HON:WEST means West wind. Their mappings are explicit and distinct. No mapping relies on an ambiguous initial letter.

Only the existing 34 tile identities are included. The source's flower tiles and any alternate/red-five faces are excluded. This is a cosmetic design revision; Domain content and gameplay remain unchanged.
