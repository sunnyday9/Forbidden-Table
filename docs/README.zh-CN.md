# Forbidden Table

[English](../README.md) · **简体中文**

**用一手麻将，构筑你的闯关策略。** Forbidden Table 是一款单人、回合制的麻将 Roguelite 游戏。你需要摸牌、整理手牌、结算牌型，并在跨越两幕的旅程中不断调整自己的构筑。每个回合都要兼顾成牌机会与敌人的下一步行动，决定哪些牌值得保留，哪些可以打出。

**[下载 Windows MVP 版本](https://github.com/sunnyday9/Forbidden-Table/releases/tag/v1.0.0-mvp.1)** · [反馈问题或提出建议](https://github.com/sunnyday9/Forbidden-Table/issues)

当前版本为 **1.0.0-mvp.1**，属于面向 Windows x64 的实验性预发布版本。

![第一幕的实战界面：整理后的麻将手牌、选中的牌型、敌人意图以及手牌行动按钮](media/screenshots/battle-pattern.png)

*MVP 实际游戏画面：先查看敌人意图，再决定如何使用手牌。本文截图采用英文界面；游戏内可在设置中切换为简体中文。*

## 游戏亮点

- **把麻将牌型变成战斗决策。** 顺子、刻子和杠子可以用于换牌；对子帮助你组成完整和牌。完整和牌会把分数转化为伤害，行动预览则让你在确认前了解基础效果。
- **在旅程中逐步形成构筑。** 选择角色与契约，然后获得新牌、强化牌、遗物、技法和破规能力。奖励既能强化现有思路，也可能带来改变方向的机会。
- **跨越两幕的路线选择。** 战斗、事件、商店、工坊、精英和首领提供不同的资源使用方式与牌池改造机会。
- **每次结束回合前都要取舍。** 从手牌中打出 1–3 张牌。如果本回合打出的三张牌构成顺子或刻子，就获得 **3 枚金币**。你可以保留更好的成牌机会，也可以打出一组牌换取资源。
- **按自己的习惯整理手牌。** 按花色和点数自动整理，也可以自由拖动，或使用“向左移动 / 向右移动”。弃牌区只显示牌数，保持牌桌简洁。
- **边玩边学。** 内置“示例旅程”，在独立练习中介绍基本玩法。设置支持英语 / 简体中文、界面缩放、动画速度与减少动态效果。

## 下载与开始游戏

1. 打开 [MVP 发布页面](https://github.com/sunnyday9/Forbidden-Table/releases/tag/v1.0.0-mvp.1)，在 **Assets** 中下载 `forbidden-table-1.0.0-mvp.1-windows-x64.zip`。
2. 将 **整个 ZIP 文件解压** 到一个文件夹。请把 `ForbiddenTable.exe` 与 `ForbiddenTable.pck` 放在一起，并保留附带的说明和许可文件。
3. 运行 `ForbiddenTable.exe`。游玩导出的版本不需要安装 Godot。目标平台为 Windows 10/11 x64。
4. 打开 **设置**，选择语言与显示偏好。第一次游玩时，建议进入 **示例旅程** 并跟随提示操作；选择 **退出示例** 可返回正式旅程。

## 怎么玩

### 1. 选择起始构筑

**角色** 决定你的起始牌池、遗物、核心技法和被动能力。**契约** 会同时带来收益与代价，选择前请阅读两方面的说明。新档案可以选择顺子师和藏牌师，部分其他选项需要解锁。

![角色选择界面，展示各角色的起始牌池、遗物、核心技法、被动能力与解锁状态](media/screenshots/choose-character.png)

*角色卡片会说明你的起始工具，并标明当前档案可用的选项。*

### 2. 看清牌桌，组织手牌

战斗目标是在 **压力达到上限之前击败敌人**。查看 **意图**，了解结束回合时敌人会做什么。有可用摸牌次数时，可以从牌墙摸牌；战斗开始时拥有 **11 张手牌**，手牌最多容纳 **14 张**。

不必先掌握所有麻将计分规则，可以从以下牌型开始：

| 牌型 | 示例 | 用途 |
| --- | --- | --- |
| 对子 | 两张相同的牌 | 用于组成完整和牌；对子不能单独进行部分结算 |
| 顺子 | 同一花色的二、三、四 | 三张牌的牌型；九与一不能首尾相接 |
| 刻子 | 三张相同的牌 | 另一种三张牌的牌型 |
| 杠子 | 四张相同的牌 | 可进行部分结算；独立的“打出”额度仍然最多为 3 张 |
| 完整和牌 | 四组顺子或刻子加一个对子，或七对 | 合法的 14 张手牌，可进行完整和牌结算 |

点击牌进行选择，再查看该选牌组合提供的行动。**部分结算** 会消耗选中的顺子、刻子或杠子，并按预览补牌。小牌型主要帮助你调整手牌，伤害取决于你的构筑。**完整和牌** 会结算合法的完整手牌，造成伤害并进入恢复阶段。检查完整和牌时，可以使用 **选择全部手牌**。

**核心技法** 提供额外的战斗手段，使用前请查看效果、TP 消耗与可用状态。**备牌** 可以暂存一张牌，之后再交换回手牌；但存入的牌会在回合结束时损失完整度，完整度降至 0 时失效。稳定度效果可以帮助降低压力。决定行动时，请同时参考效果预览和敌人意图。

### 3. 打出手牌，再结束回合

在选择 **结束回合** 之前，你必须在本回合内 **累计打出至少 1 张、最多 3 张手牌**。可以一次打出，也可以分多次行动打出；这些行动共用同一回合额度。

- 选中准备舍弃的手牌，再选择 **打出**。
- 如果本回合打出的三张牌构成顺子或刻子，就获得 **3 枚金币，每回合最多触发一次**。
- 打出的牌进入 **弃牌区**，不消耗 TP，也 **不会补牌**。部分结算是另一种行动，不能替代结束回合前的打出要求。
- 打出至少一张牌之后，**结束回合** 才会可用。结束回合会结算敌人意图，并在下一回合重新计算打出额度。

**新手提示：** 先整理手牌，检查有没有完整和牌，并在消耗牌之前查看敌人意图。部分结算可以改善手牌；为了金币打出一组有用的牌，也可能让下一手更难凑齐。

### 4. 选择奖励与下一站

战斗胜利后，查看可选奖励：在相应选项出现时，你可以添加一张牌、强化已拥有的牌种，或领取资源。随着旅程推进，遗物和技法会增加效果，特殊奖励则可能改变构筑规则。金币用于购买商店商品和支付工坊服务；精炼代币支持部分强化操作。

![示例旅程获胜后的奖励界面，可以选择新增牌、强化牌或领取资源](media/screenshots/guided-sample-reward.png)

*示例旅程的实际游戏画面：比较添加二条、用港湾印记（Harbor mark）强化已有牌，或领取金币。练习奖励仅保留在本次示例中。*

在地图上选择可用目的地进行预览，再点击 **前往** 确认路线。根据资源调整选择：战斗获取奖励、探索事件、在商店购买工具，或在工坊改造牌池。完成每一幕的首领战斗和奖励选择，推进这段两幕旅程。

![第一幕路线地图，展示战斗、事件、商店、工坊、精英与首领节点](media/screenshots/choose-route.png)

*正式新旅程的第一幕地图。后续目的地会随着推进逐步揭示。*

**弃牌与永久移除不同。** 打入弃牌区的牌仍属于本次旅程的牌池，在后续战斗中仍可能出现。工坊的移除操作会永久改变本次旅程的牌池。

## 操作与显示设置

使用鼠标选择行动和牌。拖动手牌可以调整顺序，也可以选中牌或将焦点移到牌上，再使用 **向左移动 / 向右移动**。**整理手牌** 会按花色和点数分组；**清除选牌** 会重置选择。键盘支持 **Tab / Shift+Tab** 切换焦点、**Enter** 激活当前控件，以及 **Esc** 返回或取消选择。

设置支持切换 **英语与简体中文**、放大界面、调整动画速度和启用减少动态效果。教程提示可以开启、关闭或重置。本文截图来自已发布的 MVP；[截图来源说明（英文）](media/screenshots/README.md) 区分了正式旅程与示例旅程画面。

## 存档、版本状态与反馈

存档与设置位于 `%APPDATA%\Godot\app_userdata\Forbidden Table`。尝试预发布版本前，请备份这个文件夹。旧存档中的当前战斗保留原有规则，新开始的战斗使用本文介绍的手牌打出规则。手牌的显示顺序会在重启后重置。规则变更后，部分旧回放可能无法使用；1.0 之前的版本不保证普遍兼容。

此 MVP 已开放反馈。维护者表示已完成真人两幕流程验证，但固定种子测试仍有未通过的推进案例，部分平台与设备的验证也尚未完成。它尚不是议题 [#105](https://github.com/sunnyday9/Forbidden-Table/issues/105)、[#106](https://github.com/sunnyday9/Forbidden-Table/issues/106) 和 [#107](https://github.com/sunnyday9/Forbidden-Table/issues/107) 所描述的稳定版 1.0。

遇到难懂的行动、程序错误或平衡问题时，请 [提交 GitHub Issue](https://github.com/sunnyday9/Forbidden-Table/issues)，附上 **版本、语言、旅程种子、复现步骤与预期结果**。界面问题最好同时附上截图。

## 开发

<details>
<summary>从源码运行、验证与打包</summary>

使用 `scripts/GODOT_VERSION` 固定的 Godot 版本（当前为 **4.7.2**）和 Python **3.12**。在 Godot 中打开 `project.godot` 即可从源码运行。打包需要安装对应版本的 Windows x64 导出模板。Shell 脚本需要 Bash 和 GNU timeout。以下命令在仓库根目录执行。

```bash
python3 scripts/validate_localization.py
python3 -m unittest discover -s tests -p 'test_*.py'
bash scripts/test_mvp.sh
bash scripts/test.sh
bash scripts/package_windows_release.sh --output-dir dist
```

将 `GODOT_BIN` 指向已安装的可执行文件。测试包装脚本可以下载指定版本的 Linux 编辑器。发布包要求 Git 工作区干净，并附带校验值与源码、构建清单。检查步骤与验证范围见 [发布流程（英文）](release/MVP_RELEASE_WORKFLOW.md)。

MVP 功能验证配置不包含四个模拟、基准测试和语料测试套件，它们仍保留在完整验证流程中。领域术语见 [CONTEXT.md（英文）](../CONTEXT.md)。本地构建、缓存与验证材料已由 Git 忽略。

</details>
