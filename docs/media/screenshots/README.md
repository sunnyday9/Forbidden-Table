# MVP gameplay screenshots

These screenshots were captured on 2026-10-09 from the published **1.0.0-mvp.1** Windows package, using its `ForbiddenTable.pck` with the Godot 4.7.2 renderer. The images are direct, unmodified viewport PNGs at **1600 × 1000**, in English with **100% UI scale** and reduced motion enabled.

| Screenshot | Session | What it shows |
| --- | --- | --- |

| [choose-character.png](choose-character.png) | Campaign, seed `5049402` | Character selection in a fresh profile |
| [choose-route.png](choose-route.png) | Campaign, seed `5049402` | Initial Act 1 map after choosing Sequence and the Pool bias Contract |
| [guided-sample-reward.png](guided-sample-reward.png) | Built-in Sample Run, seed `53005` | Reward choices after drawing and settling a Complete Hand in the tutorial's introductory battle |

The sessions progressed through the shipped game's actions, driven by a capture script. Screens were saved from the rendered game viewport. The Sample Run uses the game's own practice setup and is labelled as practice in the main README. Capture profiles were isolated from the player's campaign saves and settings. This is scripted runtime capture; human validation is tracked separately in the release documentation.

Source package: [Windows MVP release](https://github.com/sunnyday9/Forbidden-Table/releases/tag/v1.0.0-mvp.1).
