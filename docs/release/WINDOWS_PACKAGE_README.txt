FORBIDDEN TABLE — EXPERIMENTAL WINDOWS MVP
Version: @APPLICATION_VERSION@

Extract the entire ZIP, then run ForbiddenTable.exe beside ForbiddenTable.pck.
Intended target: Windows 10 or Windows 11, x64.
Start with Guided Sample. Settings offers English / 简体中文, UI scale and reduced motion.

Sort Hand groups tiles by suit and rank. Drag tiles or use move controls to arrange them freely.
Play 1–3 Hand tiles before End Turn. Three played tiles forming a sequence or triplet earn +3 Gold.
Played tiles go to Discard without drawing replacements. Discard shows its count.

Save and settings folder: %APPDATA%\Godot\app_userdata\Forbidden Table
Back up this folder before installing a prerelease. Older saved battles retain their current rules;
new battles use the Hand-play rule. Played-tile allowance and paid bonuses survive Suspend/Resume.
Hand display order resets on restart. Some older replays are unavailable after rule changes.
Pre-1.0 saves and replays have no general compatibility guarantee.

This is an experimental MVP, not the stable 1.0 release. Automated package checks do not establish
human two-Act playability, Windows 10/11 gameplay coverage, or physical controller compatibility.
Fixed-seed simulation progression failures remain open. See RELEASE_NOTES.txt for limitations.
Read THIRD_PARTY_NOTICES.md and licenses/ for bundled dependencies and asset notices.

禁桌 — Windows 实验性 MVP
请完整解压 ZIP，在 ForbiddenTable.pck 旁运行 ForbiddenTable.exe。
建议先体验引导示例；设置可切换语言、界面缩放和减少动画。
每回合结束前需打出 1–3 张手牌；三张组成顺子或刻子时获得 +3 金币。
打出的牌进入弃牌区，不自动补牌；弃牌区仅显示数量。可整理或自由调整手牌顺序。
安装前请备份存档和设置。旧战斗保留原规则，新战斗采用打牌规则。
手牌显示顺序在重启后重置，部分旧回放无法使用。此版本尚未完成双幕人工验证。
