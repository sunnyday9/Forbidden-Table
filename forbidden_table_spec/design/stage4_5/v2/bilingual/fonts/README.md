Files are unmodified language-specific SC fonts. They are kept locally for reproducible offline review instead of loading a font service. The source project's [Sans](https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/README.md) and [Serif](https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Serif/README.md) guides document this packaging. Font hashes are recorded by the bilingual package validator. Figma uses its verified matching family/style names.

These are design-review assets. No Godot font import, runtime locale registration, release packaging or size/performance claim is included.
