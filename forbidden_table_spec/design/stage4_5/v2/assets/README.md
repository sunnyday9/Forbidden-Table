# Proposed V2 artwork

Two original raster concept assets were generated with the built-in image generation tool on 2026-10-01, then uploaded through Figma MCP's supported asset-upload flow.

| File | Original size | Proposed use |
| --- | --- | --- |
| haunted-salon.png | 1672×941 | Rain-lit supernatural Mahjong salon; root backdrop |
| character-triptych.png | 1734×907 | Three cosmetic portrait concepts for Reserve, Sequence, and Harbor reader |

The exact final prompts are saved in [art_prompts.json](../source/art_prompts.json). Originals are preserved here; the browser and Figma use crops and protective gradients, rather than destructively changing the source images.

Portraits are proposed appearances for existing Characters. They are not approved lore or production assets. Harbor reader's existing locked/unlock state is still explicit. The art introduces no new content budget or mechanics. The salon and portraits may be replaced without changing the functional components.

No reference artwork or external paid image service was used. These assets are included for design review only; final approval and production resizing/import/compression are separate work after mockup approval.
