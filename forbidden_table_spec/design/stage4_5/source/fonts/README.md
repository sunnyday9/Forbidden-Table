# Design-preview fonts

These fonts are used only by the repository mockup gallery. No game Theme or runtime asset references them.

- Noto Sans Regular / SemiBold and Noto Serif Regular: official `notofonts/noto-fonts`, `hinted/ttf/` files; downloaded 2026-09-30.
- Noto Sans SC: Google Fonts delivery subset for only the tile glyphs 東白北南中發萬. It is not a complete localization font.
- Noto Project fonts use the SIL Open Font License; see `OFL.txt`. Preserve copyright/license if distributing the preview.

Full glyph coverage, chosen font versions, runtime licensing and fallback resources must be verified before approved Godot implementation. The subset is a preview optimization, not a promise of translated locale support.
