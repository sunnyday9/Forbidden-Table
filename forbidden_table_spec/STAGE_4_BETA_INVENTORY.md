**Status:** Wayfinder research draft; not an approved Stage 4 scope.

This document provides the inventory requested by [Stage 4 research issue #73](https://github.com/sunnyday9/Forbidden-Table/issues/73). It reflects the merged repository snapshot at [HEAD 2961e18](https://github.com/sunnyday9/Forbidden-Table/commit/2961e18).

## How to read the comparison

The Stage 3 column records the accepted cumulative Alpha roster. The budget column transcribes [Project Spec §29](PROJECT_SPEC.md#29-10-content-budget-summary). The difference column is arithmetic against that published budget only; the Project Spec explicitly calls these figures budgets, not immutable constraints. It does not define an approved Beta production target, required content batch, or acceptance gate. Stage 4 budget decisions remain open in [issue #75](https://github.com/sunnyday9/Forbidden-Table/issues/75).

## Act and pool availability

These are authored catalog allocations, which should be distinguished from test coverage and from a claim that players have validated the content.

- The Phase 2 catalog supplies the original stable IDs and Act 1 pools. The Alpha Scale catalog adds the third Character, Contracts 4–6, eight Yaku, eighteen Relics, six Run Techniques, and three Tile Modifiers.
- The Act 1 build pool contains Phase 2 Relics and all fourteen Run Techniques. The Act 2 build pool adds the eighteen Alpha Relics while retaining Phase 2 Relics and all Run Techniques. The Act 2 Shop pool uses the Act 2 build membership. The shared Workshop pool combines the five Phase 2 and three Alpha Modifiers. These memberships are constructed in the [Alpha Scale catalog](../src/content/catalogs/alpha_scale_catalog.gd); current tests do not assert all of these Alpha Scale pool memberships directly.
- The Act 2 catalog adds three Boss Rule Breakers and their distinct eligibility pool, four Normal enemies, one Elite, one Boss, and six Events. The Act 2 map catalog binds encounters and Events to reachable map payloads. The [catalog tests](../tests/content_catalog_test.gd) check the Act 2 Rule Breaker pool and verify Act 2 enemy/Event map reachability.
- The accepted continuity rule carries acquired Run build state after the Act 1 Boss reward and initializes a fresh Act 2 map. See the [Stage 3 continuity contract](STAGE_3_ALPHA_SPEC.md#3-continuous-two-act-run-contract).

## Evidence limits and decisions still open

- The approved cumulative totals and Act allocation come from [Stage 3 Alpha spec §2](STAGE_3_ALPHA_SPEC.md#2-alpha-content-budget-and-act-allocation) and the maintainer decision in [issue #46](https://github.com/sunnyday9/Forbidden-Table/issues/46). Current source details are in the linked catalogs above.
- Current test sources include [catalog tests](../tests/content_catalog_test.gd), [Alpha Contract effect tests](../tests/alpha_contract_effects_test.gd), [build effect consumption tests](../tests/build_effect_consumption_test.gd), [Alpha simulation tests](../tests/alpha_simulation_test.gd), [Alpha simulation coverage tests](../tests/alpha_simulation_coverage_test.gd), [Character passive tests](../tests/character_passive_test.gd), and [meta-progression tests](../tests/meta_progress_test.gd); the active test registration is visible in [tests/run_tests.gd](../tests/run_tests.gd). These tests cover selected definitions, runtime interactions, coverage bookkeeping, and Act 2 reachability. They are not one aggregate assertion of every Alpha roster count or every Scale pool membership.
- There is no tests/alpha_scale_content_test.gd at this repository revision; any reference to that path is stale. This research update inspected test sources but did not execute them.
- The Stage 3 Exit decision in [issue #69](https://github.com/sunnyday9/Forbidden-Table/issues/69) accepted the full-roster Scale corpus evidence, including 1,000/1,000 attempts, exact repeats, and no attempt failures or replay divergences. It also records that device measurements were waived for the initial MVP scope and no human playtest occurred. Those accepted automated results do not establish balance, onboarding, accessibility, localization readiness, player preference, or observed run duration.
- The optional final Act remains unresolved by this inventory; the Stage 3 exclusion of Act 3 was Alpha scope, not a decision to exclude the optional Act from 1.0.
- The count differences are research inputs for [issue #75](https://github.com/sunnyday9/Forbidden-Table/issues/75), not approved content requirements. This document does not set a Stage 4 Beta gate.

## Scope implications

1. Characters and Core Techniques match the published 1.0 counts; the current inventory gives no count-based reason to expand those categories.
2. For other categories, a budget difference alone does not establish that every nominal item is required. Any approved additions still need an intended Act, reward pool, encounter, Event route, or Workshop path.
3. The current typed catalogs, registries, reward pools, encounters, Events, and Workshop definitions provide existing data seams for these categories. A proposal for a new core capability must satisfy the evidence bar recorded in [issue #44](https://github.com/sunnyday9/Forbidden-Table/issues/44); this inventory itself identifies no proved catalog-to-core-system gap.
4. The third Act decision and the Stage 4 budget decision remain separate from these source counts; do not infer either from Stage 3's two-Act Alpha scope.
